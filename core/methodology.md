# FIRE Methodology

FIRE = Financial Independence, Retire Early. Investment income ≥ living expenses.

## Core Formula
```
FIRE Number = Annual Expenses × 25 (4% rule)
Real Return ≈ Nominal Return − Inflation Rate
```

## Variants

| Variant | Expenses | FIRE# | SR | Timeline | Lifestyle |
|---------|----------|-------|-----|----------|-----------|
| Lean | $25K–$40K | $625K–$1M | 60–80% | 8–15 yr | Minimalist |
| Regular | $50K–$80K | $1.25M–$2M | 40–60% | 12–20 yr | Comfortable |
| Fat | $100K+ | $2.5M+ | 30–50% | 15–25+ yr | Luxurious |
| Coast | — | $100K–$500K | 0% post-coast | Fixed | Work optional |
| Barista | $40K–$70K | $500K–$1.2M | 0% post-barista | Extended | Semi-retired |

**Lean:** `Lean FIRE# = Lean Expenses × 25`. Geographic arbitrage (LCOL $20–30K/yr, SE Asia $12–20K/yr).
**Regular:** Phases: Accumulation → Growth → Transition. Tax: max 401k $23.5K, Roth $7K, HSA $4.15K/$8.3K. 80–90% equities early.
**Fat:** `Fat FIRE# = Expenses × 25` (or ×30 for 3.33% WR). Requires $200K–$500K+ income. 70–85% equities, 10–20% RE.
**Coast:** `Coast FIRE# = FIRE# / (1+r)^(RetAge − Age)`. Post-coast: 0% savings needed.

| Age | Coast# ($1M FIRE, 7% real) |
|-----|---------------------------|
| 25 (30yr) | $131K |
| 30 (25yr) | $184K |
| 35 (20yr) | $258K |
| 40 (15yr) | $362K |
| 45 (10yr) | $508K |

**Barista:** `Barista FIRE# = (Expenses − PartTime Income) × 25`. Part-time covers expenses + health insurance.
